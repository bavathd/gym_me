# Sound assets

Drop `.mp3` or `.wav` files into this folder with the following filenames, then
uncomment the matching `require(...)` lines in `lib/audio.ts`:

| File              | Trigger                                     |
| ----------------- | ------------------------------------------- |
| `ding.mp3`        | System notification appears                 |
| `tap-blip.mp3`    | Button press / typewriter tick              |
| `completion.mp3`  | Daily / Penalty Quest complete              |
| `level-up.mp3`    | Level-up sequence                           |
| `penalty.mp3`     | Penalty Zone overlay                        |

## Free sources

- [freesound.org](https://freesound.org) (CC0 / CC-BY — check each file)
- [Zapsplat](https://www.zapsplat.com) (free tier, attribution required)
- [OpenGameArt.org](https://opengameart.org) — filter by CC0
- [Pixabay Sound Effects](https://pixabay.com/sound-effects/) (Pixabay licence)

Search terms that fit the System aesthetic: "sci-fi UI", "hologram", "glitch
chime", "system alert", "cyber beep".
